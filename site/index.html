Plataforma compartilhada

Cada app do portfólio roda no mesmo edge stack da Cloudflare e compartilha o D1 unificado. Leituras cross-app via Cloudflare bindings — nunca URLs públicas entre apps siblings.

  • Frontend React 19 + Vite 8 + TypeScript
  • Runtime Cloudflare Pages + Workers (Hono)
  • Database Cloudflare D1
  • Storage Cloudflare R2
  • Auth Cloudflare Access (Zero Trust JWT)
  • AI Claude · Codex · Gemini · DeepSeek · Grok
  • Email Resend
  • Sponsorship sponsor-motor + Mercado Pago Checkout Transparente Orders API
  • Anti-abuse Turnstile + GCP NL
  • Desktop Tauri 2 (Maestro)
